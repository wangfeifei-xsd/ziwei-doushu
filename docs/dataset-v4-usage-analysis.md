# 本地数据集：分发、流式读取与 24 个场景

更新日期：2026-11-07。当前已提供应用功能及配套研究工具。详细原始抽样分析保存在 [接入前评估](dataset-v4-design-notes.md)。

## 数据与安装包

固定公开数据位于 assets/datasets/ziwei-v4.0-13d，77 个年份压缩文件合计 161,407,000 字节，附官方清单、校验表与许可。它们原样来自下载总包，已逐个核对官方 SHA-256。按年份提交 Git，单文件约 2 MB，无需 Git LFS；本地原始 tar 是重复归档，不进入仓库或安装包。分析截图和临时缓存不作为运行资源。

Tauri 通过 bundle.resources 将此目录打入桌面及移动安装资源；Web 独立包复制到 assets/datasets，并在 start.cjs 配置读取目录。构建入口先执行 dataset:verify，缺失或损坏会阻止正常构建。Node.js 最低版本为 22.15（开发锁定 24.18.1）；原生 zstd 解码器随 Rust 应用编译，不依赖用户安装 zstd 命令。

运行时只打开所需年份，按行流式解码；不把 56.58 GB 原文写入磁盘。Web 至多两路解码，原生一路，均保留至多 32 条内存记录并支持取消和读取超时。每年压缩文件约 2 MB，但解码仍需长窗口内存，不能把压缩大小当峰值内存。

## 提问上下文

普通单盘、十盘学习和合盘都在宿主侧查同生辰记录。当前命盘、选择、古籍、学习资料和历史问答继续保留。新增 dataset 字段合并到现有命盘上下文，不改变用户与助手消息的顺序。前端任意伪造的 dataset 资料不会被采用。

选段综合问题、专题与宫位；单盘最多六段且总计 3600 字符，合盘每人 1800 字符。按整段过滤时间快照、旧版亮度用语与独立许可引文，整段去重，不截断成立条件。过滤是保守文字规则，不是已经校勘所有断语；当前盘面与所选时间优先。超过 1950–2026、记录缺失或服务失败时明确标记状态，继续使用当前命盘和古籍。

## 24 个场景的实际入口

### 01. 十张教学盘的资料问答

交付形式：应用。入口：/learn。

学习提问由两端宿主读取同生辰压缩记录，过滤并选择相关段落，写入 dataset 上下文。

边界：十盘共 868,280 字节，均有 13 专题；应剔除与当前引擎冲突的亮度断语及不适用的时间句。

### 02. 个人命盘的精确匹配问答

交付形式：应用。入口：/chart。

普通单盘提问使用相同资料服务，出生键精确匹配；超范围与读取失败明确降级为当前命盘和古籍。

边界：仅覆盖 1950–2026；必须对齐换日、真太阳时、闰月和流派口径。找不到时继续用当前命盘与古籍，不能拿相邻生辰冒充。

### 03. 离线的十三专题基础阅读

交付形式：应用。入口：/dataset。

十三专题本地阅读，默认过滤时间、亮度和独立许可段落；可显式查看带标记的旧快照。

边界：静态文字是 2026-10-15 版本的快照；时间相关句子要标明基准或隐藏，不能显示成实时运势。

### 04. 跨专题的解释与追问

交付形式：应用。入口：/dataset → 提问。

问题关键词、专题与所选宫位共同确定候选专题；最多六段、单盘 3600 字符，保留完整段落。

边界：十三专题不是十三个互不相关的事实表；同一段文字不能重复拼入，多专题也不能自动推出新的应期。

### 05. 学习笔记与可导出的阅读报告

交付形式：应用。入口：/dataset → 专题阅读。

保存每盘笔记，导出包含当前命盘、来源、版本和过滤后段落的 JSON 阅读报告；问答也可导出。

边界：资料中固定的年份不能自动变成报告年份；发布时保留署名并处理单独授权的引文。

### 06. 扩充有特点的教学例盘

交付形式：应用与工具。入口：/dataset → 找盘与检索。

候选生辰用当前引擎重排并识别格局，可打开为新学习盘；index 工具支持全年份结构索引。

边界：41 是代码规则函数数，不等于全部格局种数；样本的 ms 仅是命宫首颗主星，不能直接作为格局标签。

### 07. 生辰变量对照实验

交付形式：应用。入口：/dataset → 对照学习。

十二时辰、性别和手工生辰对照；显示真实结构差异并按需读取对照盘文本。

边界：这是算法和理论的对照练习；没有真实事件标签，不能据此证明某个时辰才是当事人的真实出生时辰。

### 08. 练习题、提示和答题讲解

交付形式：应用。入口：/dataset → 练习与课程。

按当前引擎出四类练习，显示依据，支持自评掌握与复习标记。

边界：不能拿旧版解读中的一句话直接当标准答案；主观断语要保留条件和解释空间。

### 09. 课程路径与个性化复习

交付形式：应用。入口：/dataset → 练习与课程。

十课知识点与学习路径，进度保存在本机，按尚未掌握的课程推荐下一课。

边界：数据没有课程难度或学习效果标签，需要产品另行设计；无需把全库文本塞入推荐模型。

### 10. 补充星曜与宫位知识页面

交付形式：应用。入口：/knowledge/<star>/<topic>。

182 个专题入口展示已有基础星义、当前专题的真实例盘与可核验古籍；不填造私有通用断语。

边界：一张盘的综合断语不能直接复制成通用星义；整理出的内容也不是恢复上游未公开的模板源码。

### 11. 术语解释与古籍出处导航

交付形式：应用。入口：/dataset → 知识与古籍。

按星曜检索已有古籍，只有存在的段落生成出处链接；样本引用定位到对应生辰、专题与段落。

边界：样本里的引文标签不代表出处已逐条核验；《天纪》引文有独立许可范围，不能作为普通 CC BY 文本整批再发布。

### 12. 按盘面结构筛选案例库

交付形式：应用与工具。入口：npm run dataset:tools -- index --year 1990。

流式重排并导出版本化结构索引与统计；页面支持当前候选批次的格局、空宫筛选。

边界：需要生成完整结构索引；样本本身没有十二宫结构，也不应将记录数称为互不重复的盘型数。

### 13. 相似命盘与差异解释

交付形式：应用。入口：/dataset → 找盘与检索 / 对照学习。

用当前宫位、星曜、四化、亮度的集合交并比排序候选，列出各方独有结构；不是命运或关系分数。

边界：文本相似常来自同一模板，不能当命盘结构相似；相似盘也不能充当用户本人的匹配结果。

### 14. 专题段落搜索与知识检索

交付形式：应用与工具。入口：npm run dataset:tools -- dedupe --year 1990。

页面按年份和专题分批搜索；工具生成精确去重的 SQLite 段落与引用表、FTS5 索引，search 子命令查询。

边界：1990 年的 98.60% 是精确段落重复出现率，含标题和套话；不能直接推算全库唯一知识量或压缩后的索引大小。

### 15. 合盘中的双方背景资料

交付形式：应用。入口：/heming。

合盘请求分别读取双方记录，独立标记甲乙、出生键和版本，每方最多 1800 字符。

边界：数据只有单盘解读，没有配对结果或相处事实，不能从两段文本直接制造匹配分数或关系结论。

### 16. 白话、繁简与多语言辅助阅读

交付形式：应用。入口：/dataset → 结合资料提问。

手动选择白话简体、繁体或英文讲解，保留术语和原文定位；由已配置模型按需生成，不自动发请求。

边界：翻译或改写不会提高原始断语的可靠性；不得丢掉条件、否定和原文来源。

### 17. 引擎升级与解读冲突检查

交付形式：应用与检查。入口：/dataset → 资料检查。

对照当前主星、亮度与样本总论，显示时间/亮度/许可过滤数量；回归固定天同化忌版本差异。

边界：样本文字是旧版本基线，不是金标准；已观测到差异，不能只靠提示词要求模型忽略就算解决。

### 18. 生辰、字段与边界回归检查

交付形式：检查工具。入口：npm run dataset:verify / npm run test:dataset。

校验全部 77 个文件；回归闰日、无效键、年份、分页、取消、损坏文件拒绝与缓存边界。

边界：全库数量目前按 MANIFEST 汇总；只有 1990 年完成逐条语义结构扫描，不能宣称全库内容都无误。

### 19. 问答检索、引用和上下文评测

交付形式：评测工具。入口：npm run dataset:tools -- evaluate。

十盘检索与引用预算检查；自动化浏览器测试验证真实上游上下文和换盘隔离。尚不包含模型答案人工质量评分。

边界：模型答案与模板文字相似不等于正确；不以预测准确率或真实事件命中率作为本数据能提供的指标。

### 20. 原生应用的离线学习资料包

交付形式：安装包。入口：Tauri bundle.resources。

完整 77 年压缩资料随原生应用分发；Rust 宿主读资源并流式解码，无需联网下载年份包。

边界：Web 的 Node 文件读取不能直接搬进共享 React 或移动端；首包不必附全量归档，缓存须有容量控制。

### 21. 压缩归档加按需缓存服务

交付形式：读取服务。入口：server/dataset/reader.mjs / native dataset.rs。

Web 最多两路解码，原生一路；32 条内存缓存、20 秒读取限制、取消和文件校验；无全量原文落盘。

边界：tar 偏移只能定位年份；普通 zstd 流不能直接跳到任意生辰。缓存会增长，解码也需要内存，生产负载仍需实测。

### 22. 段落去重与可随机读取的派生存储

交付形式：研究工具。入口：npm run dataset:tools -- pack --year 1990。

逐条独立压缩，保存偏移与哈希到 SQLite；lookup 子命令随机读回验证。dedupe 工具另提供段落派生库。

边界：派生库可能比原始 161 MB 归档更大；不得假设去重一定使总磁盘更小，也不能打乱上下文依赖。

### 23. 清洗后的微调与蒸馏研究

交付形式：研究工具。入口：npm run dataset:tools -- training --year 1990 --limit 200。

导出待人工审核的训练候选；精确段落去重、排除时间/亮度/许可片段、按主星与格局组分区。没有自动训练模型。

边界：现有条目不是现成的多轮问答；模板重复会造成数据泄漏。训练不会恢复私有源码，也不应吞入许可另列的引文。

### 24. 盘面结构分布与教学覆盖研究

交付形式：研究工具。入口：npm run dataset:tools -- index --year 1990。

按实际处理范围统计主星组合和格局，记录源码指纹、版本、记录数量及是否部分扫描。

边界：日期×时辰×性别的均匀枚举不是现实出生人口分布；频率不能解释为真实人群比例，更不代表命运发生率。

## 工具运行与范围

研究工具默认处理 1990 年；可用 --year、--from/--to 和 --limit 指定范围。每次输出到新的 .runtime/dataset 子目录，写入来源、数据版本和当前领域源码指纹。试运行使用 24 条记录，十盘 evaluate 读取全部教学例盘。全库索引和派生数据库尚未预生成；运行全库处理会扫描大量原文并增加磁盘占用。

命令示例：

```sh
npm run dataset:verify
npm run test:dataset
npm run dataset:tools -- evaluate
npm run dataset:tools -- index --year 1990 --limit 24
npm run dataset:tools -- dedupe --year 1990 --limit 24
npm run dataset:tools -- search --db <输出目录>/paragraphs.sqlite --query 三方四正
npm run dataset:tools -- pack --year 1990 --limit 24
npm run dataset:tools -- lookup --pack <输出目录> --key 1990-01-01-0-male
npm run dataset:tools -- training --year 1990 --limit 24
```

训练候选不是审定答案，不会自动发往模型服务。划分按主星与格局组，并在单次运行内消除跨集合的精确段落重复；不保证所有语义模板已经隔离，正式研究仍须人工检查泄漏与质量。多次独立导出的文件不能直接合并当作无泄漏训练集。

## 验证与边界

数据完整性：全部 77 文件校验。真实读取：十盘十三专题与 Node/Rust 同键读取。回归覆盖：无效日期、取消、分页、32 条缓存上限、损坏文件拒绝、资料降级、双人隔离、引用预算。

应用页面提供原始快照显示、当前结构核对、专题阅读、练习与本机笔记。索引、去重、独立压缩和训练导出属于命令行工具；不把它们标成已训练模型、全库已建立检索库或预测准确率评测。

本次 24 条派生库试运行得到 10,367 次段落引用、2,557 个精确段落，全文搜索有结果；训练候选 755 段、12 个结构分组，检查没有精确段落或分组跨集合泄漏。它们是这次小批运行的统计，不能推算全库。
