# AI 解读上下文

Web 的 `/api/interpret` 与原生 App 共用 `packages/features/src/ai/prompts.ts`。两端先校验命盘，再由 `context.ts` 按字段白名单构建模型资料。

## 单盘提问

请求包含 `chart`、`messages`，以及可选的 `selection`：

```json
{
  "selection": {
    "view": "liunian",
    "liunianYear": 2027,
    "topic": "wealth",
    "palaceBranch": 5,
    "siHua": { "starName": "太阴", "siHua": "禄", "view": "liunian" }
  }
}
```

`view` 可取 `mingpan`、`daxian`、`liunian`。`topic` 可取 `overview`（命格）、`love`（感情）、`career`（事业）、`wealth`（财运）、`health`（健康）、`personality`（性格）。`topic`、`palaceBranch`、`siHua` 可省略；四化必须符合当前视图，切换年份/视图时页面清除旧四化选择。不传 `selection` 时使用本命视图及上海时区当前农历年。

页面首次载入、主题按钮和推荐卡片、宫位/四化选择、本命/大限/流年切换及年份调整，都只更新下一次提问的上下文。只有输入非空问题后点击「提问」或按回车才发送；中文输入法选字中的回车不发送。回答期间可继续修改选择，回答结束不会自动补发问题。

模型每次收到系统规则、结构化资料、当前会话的全部历史问答和本次手动问题，不再截取最近 20 条。仍保留单条消息 12000 字符和 Web 请求 256 KiB 的校验，超限时明确报错，不静默丢弃历史。结构化资料包含：

- 公历排盘日、时辰、性别、可用的原始钟表时间与闰月口径；农历日期和两套四柱。
- 五行局、命宫、身宫、命主星、身主星、阴阳性别和虚岁。
- 十二宫宫干、星曜、本命四化、亮度、大限年龄段、三方四正、空宫与借星关系。
- 全部大限区间、现实当前大限、当前流年、所选流年及其所属大限；运限十二宫对应的本命宫位和来源独立的四化叠层。
- 格局名称、描述、等级、涉及宫位、成立/加分/破格条件及规则注明的出处。
- 所选主题、运限、年份、宫位及四化；根据本次问题和这些选择检索出的仓库文献条目，最多 6 条，正文总计不超过 3600 字符。

出生姓名、城市、客户端任意附加字段不会经命盘资料透传；用户主动写进问题里的内容仍属于聊天记录。每条用户消息附带提交时的运限、年份、宫位、四化和主题快照，避免后续选择变化改写旧问题的含义。所选内容用于补充上下文，以用户手动输入的问题为准。

## 运限口径与资料范围

虚岁按农历年差加一，流年以正月初一换年。流年命宫取太岁地支，大限命宫取所属大限宫位；四化叠层沿用页面的共享领域算法。童限和超出已有大限范围时，不回退到现实当前大限。

本实现提供运限宫位映射和四化叠层，未补造独立流曜或流月/流日/流时排盘。文献使用已有公版古籍整理库，含摘录与现代说明，不标称已逐字校勘原典。每条带书名、章节、段落 ID 与阅读页链接；界面只把库中真实存在的段落渲染为可点击引用。

合盘使用同一上下文构建器，附双方资料和按合盘问题检索的参考条目。这里的提示词和检索逻辑是本地实现，不依赖上游未公开的商业断语库。

## 命盘学习

Web `/learn` 与原生 `/#/learn` 共用学习页面。目录 `packages/domain/src/ziwei/learning-cases.ts` 提供十组教学合成生辰；每组特点均由排盘回归验证，不对应名人或真实经历。子时日期指已经确定的排盘日，不再执行钟表时刻换日或真太阳时换算。

学习请求沿用单盘接口，并增加 `learningCaseId`。共用消息构建器核对例盘编号与出生年月日、时辰、性别，再从目录重新排盘；客户端改写的星曜和课程说明不会成为教学依据。除完整单盘上下文外，增加 `learning`：例盘编号、主题、特点、学习要点、十四主星基础说明及排盘口径。提示词要求按盘面事实、术语、推导过程、条件与限制讲解。

进入页面、切换示例或视图、点选宫位与四化、填入推荐问题均不自动调用模型；仅发送问题时发起请求。每条问题保留当时的范围，最新选择决定本次上下文。切换例盘会终止请求并重置对话、输入及宫位/运限选择；停止或失败的回答不进入后续模型历史，同一例盘已完成的全部对话都会带入后续提问。

## 验证

`npm run test:ai` 覆盖上下文遗漏、运限映射交叉校验、春节/童限边界、非法选择、主题检索、引用溯源、字段白名单与完整历史。浏览器用例中的“AI 上下文”覆盖 Web 实际上游请求、原生 Responses 请求、选择不自动发送、输入法回车保护、跨年份追问、四化与宫位选择、长会话和引用跳转。

## 本地压缩样本资料

Web 和原生宿主在消息校验后按出生键检索 v4.0 资料，按需流式解码，32 条内存缓存。参考结果写入现有命盘上下文的 dataset 字段；合盘分别标明甲乙，不改变完整历史的顺序。每次最多六段、单盘 3600 字符，合盘每方 1800 字符。过滤时间快照、旧亮度用语及独立许可引文，保留整段、出生键、专题、段落编号与数据版本；缺失或读取失败时标明降级状态。样本引用使用这些来源标识，不生成站内资料阅读链接；古籍引用仍链接已有阅读页。详见 [资料分发与场景入口](dataset-v4-usage-analysis.md)。
